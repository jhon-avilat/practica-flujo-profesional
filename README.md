# jhon-avilat-practica-flujo-profesional

Práctica de flujo profesional: Jira, ramas, PRs y GitHub Actions

\# Práctica flujo profesional



Mini API en Spring Boot para practicar Jira → ramas → pull requests → GitHub Actions.



\## Cómo ejecutarla

```bash

./mvnw spring-boot:run

```

Luego abre http://localhost:8080



\## Cómo correr los tests

```bash

./mvnw test

```
